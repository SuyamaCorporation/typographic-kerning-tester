# Typographic Kerning Tester

**Category:** Design & Typography Tools

Test kerning pairs with live visual feedback across multiple preview modes (headline, alphabet, common pairs, custom text). Adjust font family (system fonts or Google Fonts via CDN), size (12–120px), weight, and global letter spacing. Test and fine-tune individual letter pairs with per-pair spacing controls. Displays a grid of common problematic pairs and a diagonal letter matrix. Exports kerning reports with OpenType-style kern values. All adjustments persist in localStorage.
